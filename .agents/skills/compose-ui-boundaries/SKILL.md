# Compose 页面与组件边界

- 从生产目的地进入，记下页面依赖的状态、事件、资源、返回动作与宽窄布局。入口采集状态并接线，内容 Composable 接收展示状态和事件回调。焦点、触摸、滚动与动画等状态在实际使用处持有。
- 先查看 `shared/design-system` 的既有组件和主题令牌。多个页面共享同一种视觉和交互时复用或补齐组件，提供 `Modifier`、展示值与适量内容插槽。文案、行为和导航由功能入口按调用场景提供。
- 书架多选栏、详情章节行、阅读器 Viewer 和 Chrome 保持各自的语义和归属。页面与其默认语言、中文资源、预览及相关测试一起移动。沿用资源包及 KMP source set 约定。
- 迁移副作用时核对 effect key、返回优先级与重复消费。当前项目以屏幕既有外观、控件语义和交互为回归基线。按[验收基线](../../../docs/verification.md)用同一主题、窗口和测试数据检查影响范围。针对已有卡顿或重组证据，先定位高频状态读和绘制路径，再做性能改动。
