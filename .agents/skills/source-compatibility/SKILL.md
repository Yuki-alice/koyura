# Venera 源兼容性

- 先按生产调用链定位改动中的协议、源身份、会话、回调和持久化边界。用本地 Venera-Next 参考版本和已有原版夹具核对结果、类型、错误、取消和调用顺序。
- 扩展安装与更新沿用暂存、初始化、提交与回滚语义。验证失败或中断后，持久记录、旧运行实例与重新打开应用后的结果一致。独立检查从登录捕获到对应源会话的 Cookie 交接，日志和测试输出保持脱敏。
- 图片通路分别验证封面回调与阅读图片回调，核对按源隔离、解码失败、重试及离线读取。界面状态观察业务结果，源会话生命周期按既有宿主边界处理。
- 按[验收基线](../../../docs/verification.md)执行触及运行时、会话桥或宿主回调的 Venera 原版 SHA-256 和全回调链校验。改 HTML、会话或图片路径时使用该文所列社区源夹具，报告执行结果和跳过原因。
