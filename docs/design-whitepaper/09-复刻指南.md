## 9.2 Compose → Web 对照表

| Compose                             | Web 等价实现                                                                  | 注意                              |
|-------------------------------------|-------------------------------------------------------------------------------|-----------------------------------|
| MaterialTheme.colorScheme.\*        | CSS 变量 `--surface-container`                                                | 只允许语义名，不允许 `--blue-500` |
| MaterialTheme.typography.titleLarge | `.t-title-lg{font-size:22px;line-height:28px}`                                | 行高必须成对定义                  |
| MaterialTheme.shapes.extraLarge     | `border-radius:28px`                                                          | Sheet 仅上圆角                    |
| isTabletUi()                        | `@media (min-width:720px)` 或 `(min-width:600px) and (orientation:landscape)` | 用最小宽度，不用当前宽度          |
| TwoPanelBox                         | `grid-template-columns:minmax(0,450px) 1fr`                                   | 左栏上限 450px                    |
| AdaptiveSheet                       | `<dialog>`：手机 bottom sheet / 平板居中 460px                                | 同一 DOM，媒体查询换定位          |
| materialSharedAxisX                 | WAAPI `translateX(±30%)` + opacity                                            | 前进/后退方向相反                 |
| fadeThrough                         | 旧内容先淡出 90ms，新内容再淡入 110ms                                         | 不是交叉淡入                      |
| Haze blur(10dp)                     | `backdrop-filter:blur(10px)`                                                  | 需处理不支持时的回退              |
| Coil crossfade(300)                 | `img{transition:opacity .3s}`                                                 | 配合 `aspect-ratio` 防抖动        |
| WindowInsets                        | `env(safe-area-inset-*)`                                                      | 阅读器可全屏隐藏                  |
| HapticFeedback                      | `navigator.vibrate(10)`                                                       | 仅在状态改变时                    |
| AnimatedVectorDrawable              | Lottie 或 SVG path 动画                                                       | 只播放一次                        |

## 9.4 复刻顺序（建议）

| 阶段     | 交付                                         | 验收                                      |
|----------|----------------------------------------------|-------------------------------------------|
| 1 · 令牌 | 颜色（亮/暗/AMOLED）、字阶、间距、圆角、动效 | 切换 data-theme 不改任何组件 CSS          |
| 2 · 骨架 | 底栏/侧栏、页面容器、insets、内容边距        | 720px 处无 JS 也能完成形态切换            |
| 3 · 列表 | 书架网格 + 列表 + 徽标 + 选中态              | 360dp 2 列、1280dp 9 列；无图片也保持比例 |
| 4 · 详情 | 封面背景 + 双栏 + 章节列表 + FAB             | 封面取色后整页协调；平板左栏 450px 封顶   |
| 5 · 弹层 | bottom sheet / 居中卡片 / 对话框             | 同一内容两种形态，键盘与返回键行为正确    |
| 6 · 状态 | 空/错/载、横幅、多选、下载进度               | 全覆盖，且颜色语义不串                    |

## 9.6 复刻时最容易踩的 10 个坑

> **01 · 把截图的粉紫当品牌色**
>
> 截图是 Android 11 壁纸取色的结果。请复刻机制，不要复刻色相。

> **02 · 只做一套主题**
>
> 忽略 AMOLED 的容器分层，纯黑导航栏会让滚动内容“消失”。

> **03 · 用当前宽度判断平板**
>
> 必须用最小宽度（或等效的“设备形态”），否则旋转会闪回手机布局。

> **04 · 左栏跟随屏幕变宽**
>
> 没有 450dp 上限，1280dp 上会得到 640dp 的“空荡左栏”。

> **05 · 平板还弹底部抽屉**
>
> 同一内容应变为 460dp 居中卡片，否则大屏上视线要下移半米。

> **06 · Tab 用交叉淡入**
>
> fadeThrough 是“先出后进”，交叉淡入会显得浑浊。

> **07 · 顶栏一直有底色**
>
> 详情页首屏应是透明沉浸，滚动后才出现 surface@3dp。

> **08 · 选中态加动画**
>
> 多选要求“指哪打哪”，动画会拖慢连续选择。

> **09 · 未选中 Tab 用 78% 透明**
>
> 代码明确用 onSurface；透明会让文字在浅背景上发灰。

> **10 · 忽略封面比例占位**
>
> 不写 aspect-ratio 会导致图片加载时整页跳动，破坏阅读节奏。
## 9.7 从 tokens.css 到第一个页面

## 设计意图

复刻指南的意图是“让结构先成立，再让细节好看”。很多人会从颜色和圆角开始抄，结果做到平板时发现骨架错了，只能重写。正确顺序是先令牌（可切换）、再骨架（断点）、再列表（密度）、再详情（封面取色）、再弹层（自适应）、最后状态（空/错/载）。验收清单则是把主观的“像不像”拆成可勾选的事实。

## 复刻检查清单

- [ ] 不依赖 JavaScript，仅靠媒体查询即可完成 720px 形态切换。
- [ ] `tokens.css` 中没有任何组件选择器，组件 CSS 中没有任何 hex。
- [ ] 书架卡片使用 `aspect-ratio: 2 / 3`，图片加载前后不跳动。
- [ ] 平板左栏 `minmax(0, 450px)`，不会被内容撑破。
- [ ] 弹层用同一 DOM，在手机与平板只换定位与宽度。
- [ ] `prefers-reduced-motion` 下移除位移，仅保留淡入。
- [ ] 30 条验收清单全部通过后再进入视觉打磨。
