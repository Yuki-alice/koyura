## 本章导读

- 四种节奏：150ms 淡入、200ms 同级切换、300–350ms 层级变化、即时状态。
- 触觉只在“状态已经改变”时触发。
- 转场期间的内容稳定性：稳定 key 与 contentType。
- 阅读器悬浮栏、底部弹层、FAB、封面背景各自的动效参数。

---

动效总量不大，但每一种都对应一个明确的空间或状态问题。复刻时最忌讳“全部 300ms ease-in-out”——这里其实有四种不同节奏。

| 场景           | 实现                         | 时长 / 参数              | 目的                               |
|----------------|------------------------------|--------------------------|------------------------------------|
| Tab 切换       | materialFadeThroughIn/Out    | 200ms                    | 同级内容切换，强调“替换”而非“方向” |
| 页面 push/pop  | materialSharedAxisX          | 库默认（约 300ms）       | 表达层级前进/后退                  |
| 引导步骤       | materialSharedAxisX          | 库默认                   | 线性流程的方向感                   |
| 阅读器顶/底栏  | slideInVertically + fadeIn   | 200ms / 150ms            | 快速出现，不打断阅读               |
| 阅读器侧栏     | slideInHorizontally + fadeIn | 200ms / 150ms            | 平板/横屏的章节导航                |
| 底部弹层       | anchoredDraggable + tween    | 350ms                    | 可拖拽关闭，settle 有惯性          |
| 弹层内导航     | fadeIn / fadeOut             | 220ms（延迟 90ms）/ 90ms | 避免叠加方向转场                   |
| 设置项定位高亮 | animateColorAsState          | 3s 后消失                | 搜索跳转后指出目标项               |
| 封面/图片加载  | Coil crossfade               | 300ms × animator scale   | 减少闪烁                           |
| 导航图标       | AnimatedVectorDrawable       | 选中时播放一次           | 低成本“活感”                       |
| FAB 显隐       | animateFloatingActionButton  | Material 默认            | 有未读章节才出现                   |
| 封面详情背景   | Haze blur                    | 10dp                     | 打开封面大图时虚化背景             |
| 选择态         | 颜色/透明度切换              | 即时（无动画）           | 多选需要“干脆”                     |

## 5.1 触觉反馈

| 动作 | 触觉类型 | 触发时机 |
| --- | --- | --- |
| 收藏 / 取消收藏 | `LongPress` | 状态真正写入之后 |
| 拖动阅读器页码滑块 | `TextHandleMove` | 页码变化时逐格触发 |
| 滑动删除 | 阈值触觉 | 越过删除阈值的那一刻 |
| 长按进入多选 | 系统默认 | 多选模式建立时 |

注意：触觉只用于“状态已经改变”的时刻，不在按钮按下时泛滥使用。这与动效的克制策略一致。

## 5.2 转场中的“内容稳定性”

所有 Lazy 列表使用稳定的 key 与 contentType；转场时 `contentKey = { it.key }`，避免两个同 key 页面同时 compose 导致崩溃（代码中有专门注释说明这一 KMK 修复）。复刻时如果使用 React/Vue，等价物是给路由组件稳定的 key，并避免在转场期间重建列表。

## 5.3 动效节奏总结

> **快 · 150ms · 淡入淡出**
>
> 阅读器控件、提示层。目标是“立刻可用”。

> **中 · 200ms · 同级切换**
>
> Tab、阅读器滑入。目标是在一瞥内完成。

> **慢 · 300–350ms · 层级变化**
>
> 页面共享轴、弹层。目标是让用户理解“我从哪里来”。

---

## 设计意图

动效在这里承担的是“解释空间关系”，而不是制造氛围。Tab 切换用 fadeThrough，是因为它们是同级替换；页面 push 用 shared axis X，是因为存在前后层级；阅读器控件用短促滑入，是因为它不能打断阅读。把节奏分成四档之后，任何新组件都能被归入某一档，而不是临时拍一个 300ms。

## 复刻检查清单

- [ ] Tab 切换总时长 200ms，先淡出后淡入，不出现两页同时清晰。
- [ ] 页面转场方向与导航方向一致，返回时反向。
- [ ] 阅读器控件 200ms 滑入 + 150ms 淡入，不遮挡阅读区域。
- [ ] 多选/选中态切换无过渡动画，点击即生效。
- [ ] 列表项有稳定 key，转场期间不重建、不闪烁。
- [ ] 触觉只在收藏、页码拖动、滑动删除、长按多选时出现。
- [ ] `prefers-reduced-motion` 下可降级为淡入淡出。
