## 这是什么

这不是截图观后感，而是一份可以从零复刻的规格书。它把 Komikku 的视觉决策拆成三类信息：

| 证据链 | 内容 | 标注方式 |
| --- | --- | --- |
| Code | token、断点、尺寸、动画时长、颜色角色 | `文件:行` 或文件链接 |
| Screen | 74 张截图中的真实渲染 | 图注编号与文件名 |
| Inference | 原则与“为什么” | 各章“设计意图”小节 |

三类信息不混写。引用数值前，请先确认它属于哪一类。

## 关键结论（先看这五条）

1. **不要复刻粉紫色**。默认主题是 Monet，截图色相来自壁纸；要复刻的是“语义角色 → 组件”的映射。
2. **平板不是放大的手机**。720dp 处发生结构切换：底栏→侧栏、单栏→双栏、底部弹层→居中卡片。
3. **左栏有 450dp 上限**。`min(width/2, 450dp)` 是平板体验的核心，否则 1280dp 上会出现空荡的左栏。
4. **动效只有四档**。150ms 淡入、200ms 同级切换、300–350ms 层级变化、即时状态；没有长时间装饰动画。
5. **状态即颜色**。未读 = secondary、已下载 = tertiary、错误/NSFW = error；红色只给“需要行动”。

## 与 HTML 单页版的关系

| | Markdown 多文件版 | HTML 单页版 |
| --- | --- | --- |
| 适合 | 检索、引用、代码评审、进入仓库 | 演示、打印、分享链接 |
